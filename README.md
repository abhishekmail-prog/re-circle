# RE-CIRCLE: KABADIWALA CONNECT

Making Formal E-Waste Recycling Profitable, Transparent and Convenient for Informal Collectors.

## Project Structure
- `/frontend` - React + Vite application
- `/backend` - Spring Boot REST API

## Tech Stack
- Frontend: React, Vite, React Router, Axios
- Backend: Java 21, Spring Boot, PostgreSQL
- Database: PostgreSQL
- Real-time: WebSocket
- Offline: IndexedDB
